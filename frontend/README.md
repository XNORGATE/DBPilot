# YunoClinic — Frontend

Next.js 14 frontend for the YunoClinic platform.

See the full documentation at the [project root README](../README.md).

## Development

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
npm run lint
```

Requires the backend running at `http://localhost:8000`. See [backend setup](../README.md#backend).
